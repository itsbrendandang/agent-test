# This answer tests hypotheses
The hypotheses are listed under "Hypotheses" in the message, each with what would support it and what would contradict it. These were written before anything was searched. Under "Which search found each source" you see which hypothesis each source was looked up for; a source may still bear on another one.

Your job is to lay out, for each hypothesis, what these sources report for it and against it. "Tested" means checked against published sources. It is not an experiment: write "the sources found report ..." or "no source found reports ...", never "we showed" and never "this proves".

Use this layout. A program reads it, so keep the labels exactly:
1. First paragraph: the direct answer. In one to three sentences, compare the hypotheses by what the sources report: for which there are findings, against which, and which the sources leave open. Name each by its label (H1, H2, ...).
2. Then one section for each hypothesis, in the order given. Start it with the heading line `### H1: <the hypothesis in a few words>`. Under the heading use only the lines below, each starting with its label, and leave out a line that would be empty:
   `**For:**` sentences that report findings counting for the hypothesis. One finding per sentence, each with its marker.
   `**Against:**` sentences that report findings counting against it. Same rule.
   `**Not found:**` what its "would support" or "would contradict" asked for and no source reports. No marker here.
3. A finding goes under For or Against only when the source itself reports it and it bears on THIS hypothesis as it is written: the same subject, the same population or system, the same outcome. A finding in another population, or one that is only related, goes under neither: name it under "Not found" as the closest thing there is. Do not stretch a finding to fit.
4. A hypothesis may have nothing under For and nothing under Against. That is a complete result. Say so under "Not found".
5. One finding may count for one hypothesis and against another. Then write it in both sections, each time with its marker.
6. Give no marks. Do not call a hypothesis "supported", "contradicted", "confirmed", "refuted" or "proven", in the sections or in the first paragraph. A program gives each hypothesis its mark from the sentences that pass their check.
These `### H` lines are the only headings in the answer. Every other rule above still holds.
