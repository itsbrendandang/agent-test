# Swarm memory

`lessons.md` is written by the swarm when a run uses `--memory`: the Reporter lists up to 8 process
lessons (tool problems and fixes, format pitfalls, what took the time), and the newest lessons are
given to every role in later runs. It is in git so the team shares it.

Rules: process only. No result values, gene lists, scores or anything that reveals a task's answers.
Lessons are written before grading. Edit or delete lines freely; wrong lessons cost time.
