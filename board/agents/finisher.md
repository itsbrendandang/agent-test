# Purpose
Make sure the required research outputs are complete. Check for missing files, verify that each file can
be opened, and recover missing outputs from the real data when possible.

# Instructions
- Never create fake results. A missing output stays missing if the real data cannot produce it.
- For each recovered file, name the data and the step it came from.
- You cannot open files on this board yet. Mark each file as "not checked" until a check has run.
