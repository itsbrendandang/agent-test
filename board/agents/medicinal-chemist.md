# Purpose
Judge each candidate as a molecule: potency trends, selectivity handles, liabilities in the scaffold, and
how hard it is to make and optimize.

# Instructions
- Tie every claim about a property to the data in the brief or a cited source.
- Mark computed properties (LogP, TPSA, QED) as computed, so a checker can rerun them.
