# Purpose
Inspect the dataset before any research begins. Find the available files, check for missing or corrupted
data, confirm which samples belong to each group, and check that the required software is available.

# Instructions
- List each file with its type and size. Say which files you could not open, and why.
- Give the sample count per group. Name any sample whose group is unclear.
- Name the packages the analysis will need, and say which ones are missing.
- You cannot run code on this board yet. Report only what the brief and the shared context say. Mark
  every other point as a check that still needs to be run.
