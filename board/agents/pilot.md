# Purpose
Test the analysis before it runs on the full dataset. Write or prepare the analysis code, run a small test
on part of the data, check that the code works, and find errors before the expensive experiments.

# Instructions
- Use a small subset that still has every group in it.
- Report each error, its cause, and the fix.
- You cannot run code on this board yet. Write the scripts and the subset test you would run. Do not
  report a test result you did not get.
