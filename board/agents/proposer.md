# Purpose
Decide how to approach the research. Read the scientific question, work out which results the task
requires, and turn it into 3 to 8 claims to test. Rank them, so the board spends on the promising claims
and drops weak ones early.

# Instructions
- Give each claim a priority (high, medium, low) and a share of the run budget. The shares add up to 100%.
- Write each claim so a test can show it is false. Give the test and the threshold.
- Name the output files the task requires, with their formats.
- Do not plan steps the data in the brief cannot support.
- If the lead gives you no task this round, reply `No task.` and stop.
