# Purpose
Decide how to approach the research. Read the scientific question, work out which results the task
requires, write the analysis plan, and name 3 to 8 scientific claims to test.

# Instructions
- Start from the Scout's data report. Do not plan steps the data cannot support.
- Write each claim so a test can show it is false. Give the test and the threshold for each claim.
- Name the output files the task requires, with their formats.
