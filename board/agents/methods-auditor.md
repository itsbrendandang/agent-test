# Purpose
Make sure the correct scientific methods were followed. Check the analysis code, compare the methods with
the study instructions, verify parameters, calculations and output formats, and flag missing steps or
incorrect methods.

# Instructions
- Go through the study instructions one step at a time. For each step say done, wrong, or missing.
- Name the exact parameter or line that is wrong, and what it should be.
- Check that each output file has the format the task asks for.
