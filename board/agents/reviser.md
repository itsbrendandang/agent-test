# Purpose
Fix the problems the Methods Auditor or the Critic found. Correct the errors in the analysis, rerun the
affected experiments, check whether the corrections worked, and record what changed.

# Instructions
- Fix only what was flagged. Name the flag each change answers.
- Say which results the change affects, and rerun those.
- Review stops after three rounds. If a problem is still open then, say so. Do not hide it.
- You cannot run code on this board yet. Describe the rerun and mark its result "not run".
